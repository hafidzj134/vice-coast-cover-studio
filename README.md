Vice Coast Cover Studio is an offline web app that turns your own photos and a caption into GTA-style multi-panel cover art: six panel layouts, five sunset/neon colour grades, per-panel crop and position, Anton + Pacifico lettering, and PNG export in 1080 x 1080, 1080 x 1350 and 1920 x 1080. Photos are read on your own machine and never uploaded.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Hand in with `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
